# Review thay đổi code
Phạm vi: repo/PR hoặc patch được cung cấp.
Base/head: SHA thực nếu đã resolve, nếu không là nhãn fixture.
Nguồn standards:
Nguồn spec và phần chưa có:

## Standards
Findings có locator, trigger, expected/actual, impact và hướng sửa.
Phân biệt hard requirement, heuristic và needs_validation.

## Spec
Findings hoặc no spec available; không dùng no findings thành spec pass.

## Tests và bằng chứng
Đã chạy: command/head/exit và kết quả.
Chưa chạy: lý do/phạm vi.
Ca đề xuất: positive/negative/boundary sát thay đổi.

## Giới hạn
Phần chưa đọc, context/guard chưa thấy, reviewer độc lập có/không.
Không tự sửa, merge hoặc deploy.
